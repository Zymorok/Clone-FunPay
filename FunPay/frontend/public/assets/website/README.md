# Website Assets

Здесь лежат ассеты сайта.

## Папки

- `offers/` - картинки для карточек популярных предложений.
- `animations/icons/` - маленькие SVG-анимации для интерфейса.
- `animations/characters/` - персонажи и крупные анимации.
- `backgrounds/` - фоны.
- `illustrations/` - обычные иллюстрации.
