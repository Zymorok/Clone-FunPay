# Документация FunPay

Здесь хранится рабочая документация проекта.

## Разделы

- `project/` - описание проекта и MVP.
- `backend/` - заметки по backend.
- `frontend/` - заметки по frontend.
- `database/` - БД, таблицы, статусы.
- `api/` - будущие endpoints.
- `plans/` - планы по дням.
- `team/` - задачи команды.

## Правило

Если меняется логика проекта, БД или API, сначала фиксируем это в документации, потом переносим в код.
