Базово готовий сайт має дозволяти пройти шлях від перегляду каталогу до профілю та взаємодії з продавцем.

- головна сторінка з категоріями та популярними пропозиціями;

- каталог товарів або послуг із картками;

- пошук, фільтри та сортування каталогу;

- сторінка окремої пропозиції з назвою, описом, ціною, продавцем і статусом;

- реєстрація, вхід, вихід і збереження сесії;

- профіль користувача з нікнеймом, описом і базовою статистикою;

- можливість відкрити публічний профіль іншого користувача;

- редагування власного профілю та контактів;

- створення або редагування пропозиції продавцем;

- базова взаємодія між покупцем і продавцем: контакт, заявка або замовлення;

- перевірка ролей і захист адміністративних дій;

- кастомізація профілю та статус присутності, якщо вони вже заявлені у функціональності;

- стани завантаження, порожнього каталогу, помилки та неавторизованого доступу;

- коректна робота токенів, виходу та захищених маршрутів;

- початкові дані для каталогу та тестові користувачі;

- README з описом запуску, ролей і демонстраційного сценарію.

Обов’язкова демонстрація: гість знаходить пропозицію через каталог, реєструється, входить, відкриває профіль продавця, редагує власний профіль і створює або змінює пропозицію. Звичайний користувач не має доступу до адміністративних функцій. @everyone
