# Backend

Backend делаем на ASP.NET Core Web API.

## Основные папки

- `Controllers/` - API-контроллеры.
- `Models/` - модели данных.
- `Data/` - подключение к БД.
- `Services/` - логика приложения.
- `DTOs/` - данные для запросов и ответов.

## Приоритет

1. Подключить БД.
2. Сделать модели.
3. Сделать авторизацию.
4. Сделать каталог и объявления.
5. Сделать заказы.
6. Сделать чат.
7. Сделать админку.
