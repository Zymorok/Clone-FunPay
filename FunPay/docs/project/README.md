# Project

FunPay - MVP игрового маркетплейса.

## Цель

Пользователь регистрируется, создает объявление, другой пользователь оформляет заказ и пишет продавцу.

## Входит в MVP

1. Авторизация и регистрация.
2. Каталог игр.
3. Категории услуг.
4. Объявления.
5. Страница товара.
6. Создание объявления.
7. Заказ без реальной оплаты.
8. Простой чат по заказу.
9. Профиль пользователя.
10. Мини-админка.

## Не входит в MVP

- Реальные платежи.
- Внутренний баланс.
- Автовыдача товара.
- Споры.
- Верификация продавцов.
- Уведомления.
- Избранное.
- Сложные фильтры.
