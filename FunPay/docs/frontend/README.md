# Frontend

Frontend делаем на React.

## Основные страницы

- `Home` - главная.
- `Login` - вход.
- `Register` - регистрация.
- `Catalog` - каталог.
- `Product` - страница объявления.
- `CreateProduct` - создание объявления.
- `Orders` - заказы.
- `Chat` - чат.
- `Profile` - профиль.
- `Admin` - мини-админка.
